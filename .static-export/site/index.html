Aplikasi gagal dimuat

Berkas HTML sudah terbuka, tetapi bundel JavaScript tidak berhasil dijalankan. Penyebab yang paling sering terjadi:

  • Berkas di folder assets/ tidak ikut terunggah, atau diunggah tidak lengkap.
  • Halaman dibuka lewat file://. Paket ini harus diakses melalui web server (http/https).
  • Server menyajikan .js dengan tipe MIME salah, atau mod_rewrite/AllowOverride All nonaktif sehingga .htaccess diabaikan.
  • Cache lama di browser atau CDN — coba muat ulang dengan Ctrl/Cmd + Shift + R.

Buka Console pada Developer Tools browser untuk melihat berkas mana yang 404. Panduan lengkap ada di README-DEPLOY.md di dalam paket ini.
